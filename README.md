## The word

**thing**

The emptiest word in the language — and the one nobody can live without.
Delete it and nobody can ever point at something and say "that thing" again.
Everyone would have to actually know the name of everything.

## How it works

`main.ts` (Node 22) writes exactly one word, `thing`, to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Nothing else. No newline, no
explanation — the word is the whole entry.

```sh
node main.ts
```
